⏺ Code facts. These are numbers code computes and puts into the reader's input:
  "Marcus last wrote 4 business days ago," "Avery wrote last," "these two events
  overlap," "the task list is 11 days old." They're essential, because LLMs are
  bad at date math.

  Safety nets. These are 9 code checks that run next to the reader and create
  their own digest items: Marcus waiting 3+ business days, a meeting over deep
  work, a family calendar clash, a double booking, 3+ recruiters from one firm,
  a stale source, suspicious content, and an automated "please approve." The
  idea was that if the reader missed something, code would still catch it.

  Linker. Now both the reader and a net can produce "reply to Marcus." The
  linker (Jev, or the LLM when Jev is unsure) decides whether the two are the
  same item. If they are, the net's fact is attached to the reader's item; if
  not, the net's item is kept as a "rescue."
