  # Export Session Transcripts: Official Documentation

  ## Quick Answers

  1. **Is there a `/export` slash command?**
     - YES. Opens a menu to copy/save conversation as plain-text file
  (human-readable, not JSONL). Accepts optional filename: `/export
  transcript.txt`
     - Source: https://code.claude.com/docs/en/sessions.md

  2. **Where does Claude Code store raw transcripts on macOS?**
     - Path: `~/.claude/projects/<project>/<session-id>.jsonl`
     - `<project>` = working directory path with non-alphanumeric → `-`
     - Format: JSONL (internal, unstable across versions)
     - **NOT SAFE TO COMMIT**: "The entry format is internal to Claude Code and
  changes between versions, so scripts that parse these files directly can break
  on any release."
     - Source: https://code.claude.com/docs/en/sessions.md

  3. **Is there a `claude` CLI flag to export past sessions non-interactively?**
     - **Not documented.** Only `/export` (interactive). For programmatic
  access, use `claude -p --resume <session-id> --output-format json
  "summarize..."` to send a follow-up and capture structured JSON response, but
  this doesn't export the past transcript—it resumes it.
     - Source: https://code.claude.com/docs/en/sessions.md

  4. **Does VS Code extension support the same export?**
     - YES. Same `/export` command. The extension shows: "Select **Export
  conversation**...or type `/export`...Add a file name such as `/export
  notes.txt`" (requires v2.1.280+).
     - Source: https://code.claude.com/docs/en/vs-code.md

  5. **Caveats: Do exports include secrets? Scrubbing needed?**
